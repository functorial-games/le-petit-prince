# Native pilot-face source provenance

Application base: `functorial-games/le-petit-prince`
`212662217cf5294be5f4add3a5d9ea95176bd9f9` (`main`). The old
`isomorphismes/le-petit-prince` identity redirects to this repository.

Beauty reference: `functorial-games/beauty`
`34d0b6e04023c8ca4e7dd25b2381a2128f12c03a` (`main` at inspection).
Read `examples/autogenerated/moving-face/model.mjs`, structural/render tests,
`anatomy/musculature.tsv`, `facial-mask/controls.csv` and anatomy documentation.
The imported data is only the 102 compiled actuator parameters, 36 control
recruitment gains, 2,229 rest vertices, 4,184 triangles, 18 landmarks and rest
jaw/hyoid points. A host reference runner imports Beauty from a separate
revision-verified clean checkout and regenerates these data byte-for-byte.
The upstream repository, demo, source images and browser machinery are not copied.

Canonical substrate: `isomorphisms/android-NDK`
`d4a4719fb97e8031476bf822697dce8423bc9030`. Read `ARCHITECTURE.md`,
`apk/README.md`, `native/README.md`, `provenance/migration-inventory.md`,
and MIRO ABI/GPU dossiers. It specifies application-owned manifest, identity,
library and signer; optional DEX; direct aapt2/zipalign/apksigner packaging.
This slice needs no generic substrate correction and adds no application code there.

Native lifecycle/EGL precedent: `isomorphismes/pauli`
`1db27e5d5451af2392fa0b74a47d9d53723682c6`:
`android/native/pauli_android.c`, manifest, native/package scripts,
and `.github/workflows/android-phone-apk.yml`. The application adapter is derived
from that event-driven NativeActivity shell, with GLES2 selection, model controls,
saved state and app-owned renderer. Its native-only packaging/signer boundary is
retained. GNU Make owns the build dependency graph; recipes are fixed commands
at Make/GitHub Actions' required shell boundary, without a new Bash build script.

Crystal inspected: `functorial-games/crystal` main
`25b63837091c92e07738b1b51865603cc4b5e63d`; current prototype branch
`test/miro-apk-prototypes` at `0ed094920683cc0eae12e7c077dd347ea3f4e9b5`.
Its C/raylib drag and reset interaction was useful reference. Its Gradle/Lua/raylib
packaging is not adopted because Pauli already supplies the smaller requested shell.

Wegert inspected: `isomorphismes/wegert`
`dfa3751f0282cdf6a2083c97063b0e8e996d0d92`. Reuse only public stable test signing
material and its fail-closed certificate verification precedent, no JNI/runtime.
The exact test signer is recorded in `signing/README.md`.

Pilot art packet: Little Prince `pilot-in-the-desert`
`ba0e091a947b0977d3736ddff609c7bdac4654ac`:
`art/pilot-in-the-desert/{README.md,facial-rig.md,contact-sheet.webp}`.
Read both briefs and viewed the preserved contact sheet. References stay on
their existing branch untouched. The neutral Beauty mask is not fitted to this
heavyset, tired, mustached pilot. Brown flat shading is diagnostic; a pilot sculpt,
mustache, painterly texture and exhaustion/astonishment acting remain future work.

Runtime: framework NativeActivity -> NDK native app glue -> portable C state,
anatomical activation, skeletal pose and skin deformation -> application GLES2
renderer -> EGL / ANativeWindow. No application DEX, JNI, JS, HTML, WebView,
Java/Kotlin source or engine. Java on the build host supports existing SDK signing
utilities only. The C core uses doubles; GL upload uses floats. Rest data is baked
from the current reference, not a new procedural sculpt.

Numerical differences: reference/native tolerance is `2e-9 * (1 + abs(reference))`
for each quantity. The first host run compared 1,455,642 quantities across 213
cases with maximum absolute difference `2.8421709430404007e-14`. Core semantics,
vertex order, topology, activation order, control CSV order, saturation, jaw opening
suppression, modiolus coupling, bounded fields and strain backtracking are retained.
Browser strain diagnostics listing failed triangles is not exposed by the native
result; unsafe final poses instead return false. Core input addresses independent
actuator indices; browser convenience alias names are not a native UI/API feature.

Target: MIRO A1, Android 14/API34, `armeabi-v7a`, AArch32, 32-bit pointers,
ARMv7-A softfp public ABI, PowerVR GE8322, 576x1152, 4096-byte pages.
Compiler target is `armv7a-linux-androideabi21`, explicitly A32/softfp;
NDK `29.0.14206865`, build-tools `36.0.0`, compile/target SDK34, min SDK21.
ICK remains desirable; the verified ICK Android graphics/lifecycle/full face
path is absent here, so this requested slice uses the NDK directly.

Host core, reference, host Mesa graphics, Android ELF, aligned signed package,
CI artifact upload, emulator launch and physical-device behavior are separate
evidence. No emulator environment was available at inspection. Physical MIRO A1
installation, launch, interaction and repeated manipulation remain **PENDING**.
