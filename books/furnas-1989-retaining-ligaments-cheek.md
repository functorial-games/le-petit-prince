# Furnas (1989) — *The Retaining Ligaments of the Cheek*

**Reference:** David W. Furnas, *Plastic and Reconstructive Surgery* 83(1), 11–16, 1989. DOI: 10.1097/00006534-198901000-00003.

## Summary

Furnas is a foundational surgical-anatomy source for ligamentous fixation of cheek soft tissue to deeper structures. Later facial-space and fat-compartment literature builds on and refines this retaining-ligament picture.

## Importance to this repository

The key modeling lesson is that cheek tissue is neither completely fixed to bone nor freely sliding everywhere. Local retaining structures create spatially varying mobility.

For the heavy pilot, that matters for:
- cheek sag/roundness;
- jowl transition;
- smile/squint deformation;
- localization of folds and curvature.

Use this source for anatomical placement concepts, not for unsourced spring constants.
